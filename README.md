## Overview

Pixa Wallet gives AI agents a controlled way to pay, fetch, settle, and operate with budget limits on Algorand.

This repository contains the public product website, and static docs.

## Run Locally

```powershell
npm.cmd install
npm.cmd run dev
```

Open:

```txt
http://localhost:3000
```

## Commands

```powershell
npm.cmd run lint
npm.cmd run build
npm.cmd run start
```
