# Pixa Wallet Website

Cinematic product website and docs for Pixa Wallet, the MCP-native agentic payment wallet for Algorand and x402.

## Commands

```bash
npm.cmd install
npm.cmd run dev
npm.cmd run lint
npm.cmd run build
```

## Routes

- `/` - Product website
- `/docs` - Static documentation

## Assets

Required media assets live in `public/assets/`.
